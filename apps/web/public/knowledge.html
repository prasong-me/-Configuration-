Configuration Knowledge

หน้านี้อธิบายข้อมูลพื้นฐานที่ใช้ใน Configuration Platform โดยไม่ผูกกับ Target ใด Target หนึ่ง

IP Address

IPv4 ใช้ 4 กลุ่มตัวเลขคั่นด้วยจุด เช่น 192.168.1.10 ส่วน IPv6 ใช้กลุ่มฐานสิบหกคั่นด้วย : และสามารถย่อช่วงศูนย์ด้วย :: เช่น 2001:db8::1

IP Prefix

Prefix บอกความยาวของส่วนเครือข่าย เช่น IPv4 192.168.1.0/24 มี prefix 24 และ IPv6 2001:db8::/64 มี prefix 64 ใน Common Model เราเก็บ address และ prefix แยกกัน

Port

Port เป็นหมายเลขช่องทางบริการตั้งแต่ 1 ถึง 65535 ส่วน Protocol ระบุวิธีการสื่อสาร เช่น TCP และ UDP สองสิ่งนี้ไม่ใช่สิ่งเดียวกัน

DNS

DNS แปลงชื่อโดเมนเป็นข้อมูลที่ใช้เชื่อมต่อปลายทาง เช่น IPv4 หรือ IPv6 DNS อาจใช้ cleartext หรือ encrypted transport เช่น HTTPS และ TLS ตามความสามารถของ Target

Protocol Relationship

Protocol แต่ละชนิดมีหน้าที่และข้อจำกัดต่างกัน การเลือก protocol จึงไม่ใช่การเปลี่ยนคำเรียกของ protocol อื่น และ Target แต่ละตัวอาจรองรับไม่เหมือนกัน

Apple MobileConfig

Apple Configuration Profile สามารถบรรจุ payload หลายชนิด เช่น Web Clip และ DNS settings ได้ ส่วนความสามารถที่ต้องพึ่ง Network Extension หรือแอปของผู้ให้บริการอาจต้องมี component นั้นอยู่บนอุปกรณ์ก่อน ระบบจะสร้าง configuration และแจ้งคำเตือนตามค่าที่ผู้ใช้เลือก
