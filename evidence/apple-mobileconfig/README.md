# Apple MobileConfig Evidence

Store sanitized, reproducible evidence here.

Recommended files:
- `export-validation.json`
- `macos-install.json`
- `ios-install.json`
- `mdm-deployment.json`
- screenshots/log excerpts without credentials, private keys, tokens, or personal identifiers

Evidence status:
- `generated`: exporter produced the artifact
- `tested`: automated structure/export tests passed
- `device-verified`: real Apple device installation and behavior were observed
- `mdm-verified`: deployment and behavior were observed through MDM

Never upgrade status based only on a unit test.
